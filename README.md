## Ce face?

O aplicație **single-file** (un singur `index.html`) cu:

- 📚 **Lecții MRU & MRUV** — simulări animate și grafice interactive
- 🔬 **Laborator Newton** — simulator `F = m · a` cu grafice în timp real
- 🧠 **Quiz** — 10 întrebări cu feedback instant
- 📐 **Probleme rezolvate** — soluții afișate la click
- 🎮 **Joc** — lansator de proiectile bazat pe MRUV
- 🤖 **Dashboard Robot** — control WiFi live al unui ESP32 Line Follower

---

## 🚀 Cum rulezi

Descarcă `index.html` și deschide-l direct în browser. Atât.

Sau vizualizează live pe **GitHub Pages**:
`https://<username>.github.io/<repo>/`

## 🤖 Conexiune Robot

| | |
|---|---|
| **WiFi AP** | `RoboLineFollower` / `robot1234` |
| **IP robot** | `192.168.4.1` |
| **Control** | D-pad, taste WASD, mod AUTO |
| **Video** | Stream ESP32-CAM MJPEG |

Dacă robotul nu e conectat, dashboardul rulează automat în **mod DEMO** cu date simulate.
